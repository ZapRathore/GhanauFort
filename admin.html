यह सिर्फ़ इसी browser में सेव होती है। Token किसी को न दें।

Token बनाने का तरीका:

  1. GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access: Only select repositories → अपनी वेबसाइट वाली repo चुनें
  3. Permissions → Repository permissions → Contents: Read and write
  4. Generate करके token यहाँ paste करें
